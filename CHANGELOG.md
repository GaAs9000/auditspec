# Changelog

## 1.3.0

- add a finite exact information-order calculus for auditability;
- emit quotient/factorization certificates or constructive evidence twins;
- compile dependency-closed, catalog-cost-optimal contracts from
  claim-critical-pair separators;
- separate sufficiency, deletion minimality, and lower-cost optimality
  certificates;
- certify claim-relative lifecycle preservation and hard semantic loss;
- prove collision persistence for deterministic post-processing and compute
  semantic audit horizons;
- bind globally lossy Vault migrations to per-claim certificates instead of
  rejecting or accepting every claim uniformly;
- classify hard semantic and soft trust/interpretability obstructions;
- verify Python-generated claim-relative migration bundles in the Rust
  consumer.
